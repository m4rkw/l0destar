# Mission statement

Create the world's best completely open-source vehicle tracker.

A fit-for-purpose, featureful, extremely low power and high performance tracker with a free and open-source end-to-end tracking platform to go with it.

Create a truly great product using the best available components that anyone can use as a reference to build their own.

Create a great product simply because we want to use a great product, with no profit motive.
