# Overview

l0destar is a fully open-source vehicle tracker — open hardware and open software.

Inspired by the [Geolink Opentracker](https://github.com/geolink/opentracker/)
and the [Fortebit Polaris](https://www.fortebit.tech/polaris/), the goal is to build
something that will last: a reference project for the best possible vehicle tracker that
anyone can use. The hardware and software are completely open and can be revised and
maintained as a community project as technology progresses.
